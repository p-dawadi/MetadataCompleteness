# Fitch parsimony / permutation test — results

Topology-based test for association between country of origin and phylogenetic
tree position, replacing the adjacency-based (rendering-order-dependent) proxy
used in the original manuscript submission. Method and code:
[`code/parsimony_permutation_test.py`](../code/parsimony_permutation_test.py).
Tree: [`phylogenetics/final_tree/Aligned.Strepto.aln.treefile`](../phylogenetics/final_tree/Aligned.Strepto.aln.treefile)
(IQ-TREE 2.4.0, K2P+R2). Metadata: [`data/curated_metadata.csv`](../data/curated_metadata.csv).
9,999 label-shuffling permutations per test, topology held fixed, seed 20260827.

| Analysis | n tips | n states | Observed score | Null mean ± SD | Null range | Empirical p | Observed / null mean |
|---|---|---|---|---|---|---|---|
| Full dataset | 274 | 19 | 103 | 173.53 ± 3.60 | 159–186 | < 0.0001 | 59.4% |
| Excluding composition-test-failing sequences | 271 | 19 | 102 | 170.84 ± 3.57 | 154–183 | < 0.0001 | 59.7% |
| Leave-major-study-out (128 records removed) | 146 | 19 | 72 | 93.91 ± 2.26 | 84–100 | < 0.0001 | 76.7% |
| Directly-reported locations only (institution-inferred excluded) | 237 | 14 | 71 | 137.80 ± 3.52 | 124–148 | < 0.0001 | 51.5% |

**Interpretation.** In every variant the observed Fitch parsimony score is far
below the null distribution generated by permuting country labels across the
same fixed tree topology, and the empirical p-value is below the smallest
value resolvable at 9,999 permutations (1/10,000). This means tips sharing a
country of origin are more closely related on the tree than expected by
chance, i.e. there is a genuine phylogeographic signal — not an artifact of
tree rendering order (the original, retracted statistic), of the four
sequences that failed IQ-TREE's composition-homogeneity test, of the single
largest study contributing to each of the four best-represented countries, or
of institution-inferred (rather than directly reported) location labels.

**Reproduce:**

```bash
cd code
pip install -r ../requirements.txt
python parsimony_permutation_test.py                       # full dataset
python parsimony_permutation_test.py --exclude-composition-failing
python parsimony_permutation_test.py --leave-major-study-out
python parsimony_permutation_test.py --directly-reported-only
```
